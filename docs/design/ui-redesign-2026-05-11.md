# StandBy Us UI 重新设计

## 1. 产品分析

| 维度 | 分析 |
|------|------|
| 产品类型 | 社交 - 情侣私密状态共享 |
| 目标用户 | 两人私用，20-35 岁，情感连接需求 |
| 风格方向 | 温暖、亲密、柔和、情感化 |
| 设计关键词 | warm, intimate, soft, playful, emotional, cozy |

## 2. 设计系统

### 2.1 配色方案

**品牌色（暖橙 → 玫瑰渐变）：**

| Token | 色值 | 用途 |
|-------|------|------|
| `primary` | `#FF7E67` (珊瑚橙) | 主按钮、链接、强调 |
| `secondary` | `#FFB5A7` (浅珊瑚) | 次要元素、标签 |
| `tertiary` | `#FCD5CE` (粉桃) | 点缀、装饰 |
| `error` | `#E87060` (柔和红) | 错误、解除配对 |

**情感色板（扩展现有 Feeling 颜色）：**

| 心情 | 色值 | 用途 |
|------|------|------|
| 开心 | `#FFD93D` → `#FF9F43` | 😊 |
| 难过 | `#74B9FF` → `#A29BFE` | 😢 |
| 疲惫 | `#B2BEC3` → `#636E72` | 😫 |
| 悠闲 | `#55EFC4` → `#00B894` | 😌 |
| 想你了 | `#FD79A8` → `#E84393` | 🥰 |
| 睡前 | `#A29BFE` → `#6C5CE7` | 😴 |

**语义色：**

| Token | 浅色 | 深色 |

### 2.2 字体系统

| Role | Size | Weight | Line Height | 用途 |
|------|------|--------|-------------|------|

| `headlineMedium` | 20sp | SemiBold | 28sp | 卡片标题 |
| `titleLarge` | 18sp | SemiBold | 24sp | 配对码、栏目标题 |
| `titleMedium` | 16sp | Medium | 22sp | 状态卡片名字 |
| `bodyLarge` | 16sp | Regular | 24sp | 状态 doing 文字 |

### 2.3 间距系统

采用 4dp 网格：4, 8, 12, 16, 20, 24, 32, 40, 48, 64

### 2.4 圆角系统

| Token | Value | 用途 |
|-------|-------|------|
| `roundedXs` | 4dp | 小标签、头像 |
| `roundedSm` | 8dp | 输入框、按钮 |
| `roundedMd` | 12dp | 普通卡片 |
| `roundedLg` | 16dp | 状态大卡片、对话框 |
| `roundedXl` | 24dp | 底部弹窗 |
| `roundedFull` | 50% | 头像、圆按钮 |

### 2.5 阴影/高度

| Level | dp | 用途 |
|-------|-----|------|
| 0 | — | 背景平面 |
| 1 | 2dp | 未激活卡片 |
| 2 | 4dp | 普通卡片、输入框 |
| 3 | 8dp | 激活状态卡片、按钮 |
| 4 | 16dp | 模态弹窗、底部栏 |
| 5 | 24dp | 庆祝动画、全屏覆盖 |

## 3. 页面布局重新设计

### 3.1 首页（HomeScreen）

```
┌─────────────────────────────────────┐
│  🔔 StandBy Us     📜  ⚙️           │  ← TopAppBar（半透明暖白）
├─────────────────────────────────────┤
│                                     │
│  ┌───────────────────────────────┐  │
│  │         🥰                    │  │  ← 59% 空间 · 伴侣大卡片
│  │     想你了 · 在看电影          │  │    渐变背景（心情色）
│  │     「今天约了这部电影好期待」 │  │    呼吸发光阴影
│  │       更新于 14:30             │  │
│  └───────────────────────────────┘  │
│                                     │
│  ┌───────────────────────────────┐  │
│  │  😊 开心 · 喝咖啡        ✏️   │  │  ← 15% · 我的状态条
│  └───────────────────────────────┘  │
│                                     │
│  ┌───────────────────────────────┐  │
│  │       ✨ 分享瞬间              │  │  ← 56dp 圆角主按钮
│  └───────────────────────────────┘  │
│                                     │
├─────────────────────────────────────┤
│  🏠           📜                    │  ← 底部导航（2项）
└─────────────────────────────────────┘
```

**关键改进：**
- 用 Vector 图标替换 emoji 导航（🏠 → Home icon, 📜 → History icon）
- 状态大卡片增加呼吸发光效果（已有 `AvatarWithGlow` 但可扩展）
- "我的状态" 条增加颜色指示器（显示当前心情色的小圆点）
- 主按钮使用 brand gradient 而非纯色
- 底部导航使用 MDC 规范（icon + label）

## 6. 反模式检查

- ❌ 当前使用 emoji 作为导航图标（🏠 📜）→ 改为 SVG vector icons
- ❌ 当前颜色使用硬编码 `Orange` → 改为语义 token
- ✅ 触摸目标大小已满足 44dp+（按钮 56dp）
- ✅ 文本对比度 OK（暖白底 × 深棕文字）
- ❌ 动画时长未统一 → 统一 150-300ms
- ✅ 加载状态有 spinner 反馈
