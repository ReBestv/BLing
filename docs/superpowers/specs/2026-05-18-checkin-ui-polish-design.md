# Checkin 打卡页面 UI 调整

**日期**: 2026-05-18
**状态**: 设计确认 ✅

---

## 1. 概述

对已实现的 Checkin 打卡页面进行 UI 细节调整：缩小打卡按钮、重新排列内容顺序、替换今日统计中的时间字段为间隔。

### 改动目标

1. **打卡按钮缩小**：200dp → 100dp，去除文案只保留 💩 emoji，保留径向渐变 + 水波纹动画
2. **内容重排**：PK 对决移到滚动区域最顶部，去掉日期显示和副标题
3. **字段替换**：今日统计第二列从"首次打卡时间"改为"最近两次打卡间隔"

## 4. 今日统计：间隔字段

### 4.1 字段替换

| 列 | 原内容 | → | 新内容 |
|---|---|---|---|
| ② | ⏰ **HH:mm** / "时间" | → | ⏰ **XhXm** / "间隔" |

### 4.2 计算逻辑

```
获取最近两次打卡时间戳 → 计算差值（毫秒）→ 格式化为 XhXm
```

- 取 `lastTwo[0]`（最近）和 `lastTwo[1]`（次近），计算 `diff = abs(lastTwo[0] - lastTwo[1])`
- 格式化：`diff >= 3600000` ? `${diff / 3600000}h${(diff % 3600000) / 60000}m` : `${diff / 60000}m`
- 如果记录不足 2 条 → 显示 "—"

### 4.3 数据层改动

**CheckinDao** 新增查询：
```kotlin
@Query("SELECT timestamp FROM checkin_records WHERE userId = :userId ORDER BY timestamp DESC LIMIT 2")
suspend fun getLastTwoCheckinTimes(userId: String): List<Long>
```

**CheckinViewModel** 改动：
- 移除 `firstCheckinTime` 相关逻辑
- 新增 `lastInterval` 字段到 `CheckinUiState`
- 新增间隔计算 private 方法

### 4.4 UI 展示

**Emoji 背景色**：保持原浅蓝圆圈底色（`Color(0xFFE3F2FD)`）

| 状态 | 显示 |
|---|---|
| 正常间隔（< 24h） | ⏰ **8h30m** |
| 较长间隔（≥ 24h） | ⏰ **24h+** |
| 不足两次记录 | ⏰ **—** |
